# نبض المبيعات — لوحة تحليل تفاعلية

تطبيق Streamlit لتحليل بيانات شركة تجزئة تجريبية. مصدر البيانات موجود داخل مجلد التطبيق في `data/raw_retail_sales.csv`، ويجري التطبيق تنظيفًا قابلاً للتكرار قبل التحليل.

## التشغيل محليًا

من داخل مجلد `sales_dashboard`:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

## النشر على Streamlit Community Cloud

هذا المجلد مستقل وجاهز ليكون مستودع GitHub. بعد رفع محتوياته، اختر `app.py` كملف التطبيق في Streamlit Community Cloud.

للتوصيات التوليدية الاختيارية، أضف في **App settings → Secrets**:

```toml
OPENAI_API_KEY = "ضع_المفتاح_هنا"
```

يمكن اختيار نموذج API عبر متغير البيئة `OPENAI_MODEL`؛ الافتراضي `gpt-5.5`. لا تضع المفتاح داخل ملفات المشروع أو Git.

## التنظيف المطبق

- إزالة الصفوف المتطابقة تمامًا.
- إزالة المسافات العادية وغير القابلة للكسر من النصوص، وتحويل `N/A` إلى قيمة ناقصة.
- تحويل الأعمدة الرقمية والعملات إلى أرقام، ومعالجة القيم غير الصالحة والعلامات الوهمية مثل `9999`.
- اعتبار العمر خارج 1–100، والكمية أو السعر أو أيام الشحن غير الموجبة، والخصم خارج 0–100% قيمًا غير صالحة.
- إعادة حساب المبيعات عندما تتوفر الكمية والسعر والخصم، وإعادة حساب الربح عندما تتوفر المبيعات والتكلفة.

يجب تفسير النتائج باعتبارها بيانات تعليمية تجريبية، لا سجلات مالية حقيقية.
